# Hoberg Edu

> **Discover. Apply. Study Abroad.**

Hoberg Edu is a global education opportunity platform helping students and graduates in Nigeria discover international universities, Bachelor's, Master's, and PhD programs, scholarships, funding opportunities, and deadlines.

## Features
- **Public Opportunity Discovery**: Filter by degree, country, intake, tuition, and funding type.
- **Verified Sources Only**: Curated opportunities from official university portals and government education ministries.
- **Personalized Eligibility Matching**: 0-100% match score with transparent recommendations without false guarantees.
- **Application Tracker**: 8-stage progress tracker with custom checklist (CV, SOP, Transcripts, Recommendations).
- **Paystack Recurring Premium**: ₦5,000/month subscription with secure HMAC SHA-512 webhook verification.
- **Supabase PostgreSQL & Storage**: Strict Row Level Security (RLS) and private CV storage.
